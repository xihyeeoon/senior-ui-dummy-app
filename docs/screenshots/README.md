# 재현 근거 스크린샷 (실제 KB스타뱅킹 캡처)

A1/A2 화면을 **1:1로 정밀 재현**하기 위한 원본 캡처를 넣는 곳입니다.
여기 있는 이미지는 **참조용**이며 앱에 번들되지 않습니다 (`pubspec.yaml`의 `assets:`에 등록하지 않음).
앱에 넣을 이미지는 `assets/`에 따로 둡니다.

## 넣는 법

**파일명은 신경 쓰지 말고 순서만 맞춰 주세요.** 각 폴더 안에서 이름순으로 정렬되므로
`01.png`, `02.png` … 처럼 번호만 붙이면 됩니다.

```
docs/screenshots/
├─ a1/                  # 기본 홈(간편홈 OFF) 경로
│  ├─ 01_menu/          # 전체메뉴 — 스크롤/탭 조각 순서대로 (10장)
│  ├─ 02_bill_type/     # 공과금 종류 선택 (전기/가스/수도…)
│  ├─ 03_input/         # 납부번호 입력
│  ├─ 04_confirm/       # 납부 내역 확인
│  ├─ 05_auth/          # 인증 (간편비밀번호 등)
│  └─ 06_done/          # 납부 완료
└─ a2/                  # 간편홈 경로 — 경로가 다르면 같은 구조로 하위 폴더 생성
```

폴더 구분이 애매하면 그냥 `a1/01_menu/`에 순서대로 다 넣고 알려주셔도 됩니다.
단계 경계는 제가 캡처를 보고 나눌 수 있습니다.

## 부분만 있어도 됩니다

없는 단계는 **추측해서 만들지 않습니다.** 캡처가 있는 화면만 정밀 재현하고,
나머지는 `템플릿` 주석을 달아 미완성임을 코드에 명시합니다
(`a1_bill_input.dart`의 기존 컨벤션과 동일).
A1이 "충실 재현 baseline"이라는 주장을 지키려면 이 구분이 중요합니다.

## 개인정보 주의

실제 앱 캡처에는 **본인 계좌번호·잔액·이름·거래내역**이 찍혀 있습니다.
연구 원칙(`README.md`: "실거래·실제 금융정보는 넣지 않습니다(0)")은 앱 코드뿐 아니라
저장소 전체에 적용하는 편이 안전합니다.

- 현재 저장소는 **Private**입니다.
- 다만 논문 부록으로 공개 전환하는 경우, git 히스토리에 한 번 들어간 이미지는
  나중에 삭제해도 히스토리에 영구히 남습니다.
- 그래서 이 폴더는 기본적으로 `.gitignore` 처리하는 것을 권장합니다.
  (트레이드오프: git 백업이 안 되므로 로컬/클라우드에 별도 보관 필요)

캡처에서 개인정보를 가린 뒤 커밋하려는 경우, 가림 처리된 버전만 넣어 주세요.
