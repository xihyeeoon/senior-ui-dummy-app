# 고령자 UI 연구 — 실험용 더미 앱 (클릭 목업 · 프로토타입)

HCI 석사 연구 *"고령자 친화 모바일 UI 재설계 자동화 도구"*의 **평가용 클릭 목업 / 프로토타입** 저장소입니다.
진단→재설계 **엔진(도구)** 코드는 별도 저장소 `senior-ui-redesign`에 있습니다. 이 repo는 그와 독립적입니다.

## 역할 (연구 계획 §4.5)

인터뷰·평가에서 참가자에게 보여줄 **클릭 가능한 화면**을 담습니다. 실거래·실제 금융정보는 넣지 않습니다(0).

- **A1 (원본 재현)** — 실제 배포 앱(신한 공과금 납부 플로우)을 *충실히 재현*한 목업. 개선·정리 없이 원본의 불편함까지 그대로.
- **A2 (배포 고령자 모드)** — 앱에 실제 배포된 고령자/간편 모드 재현(대체로 전역 리스킨).
- **C (도구 재설계)** — 엔진(`senior-ui-redesign`)이 생성한 재설계안을 구현한 프로토타입.

> A1과 실제 앱의 1:1 대조표(충실도 입증)는 `docs/`에 별도로 관리 예정.

## 폴더 구조

```
senior-ui-dummy-app/
├─ index.html                 # 진입점: A1 / A2 / C 조건 선택
├─ css/
│  └─ base.css                # 폰 프레임 + 공통 스타일
├─ screens/
│  ├─ a1-original/            # A1 원본 재현 화면들
│  ├─ a2-elder-mode/          # A2 배포 고령자 모드 화면들
│  └─ c-redesign/             # C 도구 재설계 프로토타입 화면들
└─ assets/                    # 이미지/아이콘 등
```

## 실행

빌드 과정이 없습니다. 브라우저로 `index.html`을 열면 됩니다.

- 가장 간단: `index.html` 더블클릭
- 권장(라우팅/새로고침 안정): VS Code **Live Server** 확장으로 열기,
  또는 `python -m http.server 8000` 후 <http://localhost:8000>
